# projeto-ubs-agendamento
Sistema CRUD em Python para agendamento em uma Unidade Básica de Saúde (UBS). Projeto acadêmico focado na ODS 3: Saúde e Bem-Estar.
---

## 🎯 Desafio Escolhido
**Desafio 3 – Sistema de Agendamento de Consultas em Unidade Básica de Saúde**
* **Foco:** Otimizar o agendamento de consultas em uma UBS, visando melhorar o fluxo de pacientes e profissionais, alinhando-se ao **Objetivo de Desenvolvimento Sustentável (ODS) 3: Saúde e Bem-Estar**.
